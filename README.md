# Tanjai Video Studio

AI Video Generator ซึ่งเป็นส่วนหนึ่งของ Tanjai AI Studio ใช้สำหรับสร้างวิดีโอใหม่จากหัวข้อ บท หรือภาพ ไม่ใช่โปรแกรมตัดต่อแบบ CapCut

## Version 0.6.0 — สร้างวิดีโอตัวอย่างได้จริง

- สร้างโครงการข่าวประชาสัมพันธ์ สรุปกิจกรรม นิทาน MV หนังสั้น โฆษณา และวิดีโอจากภาพนิ่ง
- เลือกสัดส่วนและความยาวเป้าหมาย
- กรอกข้อมูลจริงที่ห้าม AI แต่งเพิ่ม
- เลือกแนวภาพยนตร์ ข่าว 3D ศิลปะ และอนิเมะ 4 แบบ
- ใช้ AI วางเรื่อง แบ่งฉาก เขียนเสียงพากย์ และ Prompt โดยแต่ละฉากไม่ซ้ำกัน
- แก้หน้าที่ฉาก เสียงพากย์ และ Prompt รายฉาก
- บันทึกร่างและเปิดโครงการเดิมจากเบราว์เซอร์
- ดาวน์โหลดโครงการ JSON สำหรับสำรองหรือส่งต่อระบบผลิต
- สร้างภาพและเสียงพากย์รายฉาก แล้วประกอบเป็น MP4 ด้วย FFmpeg
- ดาวน์โหลดชุด Prompt เพื่อนำไปใช้กับเครื่องมืออื่นได้
- เก็บกุญแจไว้ฝั่งเซิร์ฟเวอร์ ไม่ส่งไปหน้าเว็บ
- Responsive สำหรับโทรศัพท์ แท็บเล็ต และ Desktop

## เริ่มใช้งานในเครื่อง

ใช้ `npm start` แล้วเปิด `http://localhost:4173`

การวางเรื่อง สร้างภาพ และเสียงมีค่าใช้จ่ายตามการใช้งานของ OpenAI ส่วนการประกอบ MP4 ทำในเซิร์ฟเวอร์ของเราเอง

เว็บไซต์หลัก: https://thanawid.github.io/tanjai-ai-studio/
