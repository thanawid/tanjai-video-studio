# Tanjai Video Studio

AI Video Generator ซึ่งเป็นส่วนหนึ่งของ Tanjai AI Studio ใช้สำหรับสร้างวิดีโอใหม่จากหัวข้อ บท หรือภาพ ไม่ใช่โปรแกรมตัดต่อแบบ CapCut

## Version 0.5.0 — AI Video Generator Foundation

- สร้างโครงการข่าวประชาสัมพันธ์ สรุปกิจกรรม นิทาน MV หนังสั้น โฆษณา และวิดีโอจากภาพนิ่ง
- เลือกสัดส่วนและความยาวเป้าหมาย
- กรอกข้อมูลจริงที่ห้าม AI แต่งเพิ่ม
- เลือกแนวภาพยนตร์ ข่าว 3D ศิลปะ และอนิเมะ 4 แบบ
- สร้าง Storyboard เบื้องต้นในเบราว์เซอร์โดยไม่ใช้เครดิต API
- แก้หน้าที่ฉาก เสียงพากย์ และ Prompt รายฉาก
- บันทึกร่างและเปิดโครงการเดิมจากเบราว์เซอร์
- ดาวน์โหลดโครงการ JSON สำหรับสำรองหรือส่งต่อระบบผลิต
- รองรับ AI Gateway ภายนอกผ่าน `/health` และ `/v1/video-projects`
- ไม่เก็บ API Key ไว้ในหน้า GitHub Pages
- Responsive สำหรับโทรศัพท์ แท็บเล็ต และ Desktop

## สิ่งที่ทำได้ทันทีโดยไม่เสียค่า API

ตั้งค่าโครงการ บอกเรื่อง เลือกแนวภาพ สร้างและแก้ Storyboard บันทึกร่าง และดาวน์โหลดโครงการ JSON

## สิ่งที่ต้องมี AI Gateway

การสร้างภาพ วิดีโอ เสียงพากย์ การติดตามงาน และการประกอบ MP4 จริง ต้องเชื่อม Backend หรือ Gateway ที่เก็บ API Key ฝั่งเซิร์ฟเวอร์ และเชื่อมผู้ให้บริการ AI ที่เลือกภายหลัง
