# Tanjai Video Studio

เว็บตัดต่อและสร้างวิดีโอซึ่งทำงานร่วมกับ Tanjai AI Studio

## Prototype 0.4.3 — Shared Clip Handoff

- โหมดตัดต่อจากคลิปที่มี
- โหมดสร้างวิดีโอใหม่ด้วย AI
- รับ `projectId` และ `source` จาก Tanjai AI Studio
- บันทึกร่างในเบราว์เซอร์
- แสดงรายการฟุตเทจสูงสุด 30 แถวต่อครั้ง เพื่อลดภาระหน่วยความจำ
- อ่าน Metadata แบบคิวพร้อมกันสูงสุด 3 คลิป
- Preview เฉพาะคลิปที่เลือก พร้อมตัดหัว–ท้าย
- เรียง Timeline และดาวน์โหลด Edit Plan JSON
- ทดลองตัดและรวมคลิป 3–5 ไฟล์เป็น MP4 ด้วย FFmpeg WebAssembly
- ใช้ FFmpeg Core แบบ Single-thread โดยโหลดตัวประมวลผลจาก CDN ตอนใช้งานครั้งแรก
- ไม่มีไฟล์ใดใหญ่เกิน 25 MB จึงอัปโหลดผ่านหน้าเว็บ GitHub ได้
- รับคลิปที่ปรับจาก Tanjai AI Studio ผ่าน IndexedDB ด้วย `projectId` โดยไม่ต้องอัปโหลดซ้ำ
- คลิปถูกอ่านเข้ารายการและ Timeline อัตโนมัติ พร้อมคงแนวภาพและข้อมูลโครงการ
- Edit Plan JSON ถูกย้ายไปอยู่ในเครื่องมือสำหรับนักพัฒนา
- แถบสีเมนูด้านข้างติดตามหน้าหรือโหมดที่กำลังใช้งาน
- ตรวจความครบถ้วนของ FFmpeg Core ก่อนเริ่มเรนเดอร์ พร้อมแจ้งปัญหาอินเทอร์เน็ตเป็นภาษาที่เข้าใจง่าย
- ขั้นสุดท้ายของโหมดสร้างด้วย AI บันทึกร่างและพาไปโครงการของฉัน โดยไม่แสดงผลเหมือนสร้างวิดีโอจริงแล้ว
- ใช้โลโก้ Favicon โครงหน้า และ Footer ในครอบครัวเดียวกับทันใจ AI Studio
- Responsive ตั้งแต่โทรศัพท์ถึงจอ Desktop
- ยังไม่เรียก API หรืออัปโหลดไฟล์ออกจากเครื่อง

หมายเหตุ: เว็บไซต์ดาวน์โหลดเฉพาะตัวโปรแกรม FFmpeg จาก CDN คลิปของผู้ใช้ยังประมวลผลอยู่ในเบราว์เซอร์และไม่ถูกส่งไปยัง CDN
