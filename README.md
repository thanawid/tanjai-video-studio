# ทันใจ — สร้างวิดีโอ

ส่วนสร้างวิดีโอของทันใจ AI Studio สำหรับเปลี่ยนเรื่องที่เล่าให้เป็นฉาก วิดีโอเคลื่อนไหวจริง เสียงพากย์ และไฟล์ MP4 โดยไม่ใช่โปรแกรมตัดต่อแบบ Timeline

## Version 0.7.0

- รองรับงานประชาสัมพันธ์ ข่าว MV นิทาน หนังสั้น โฆษณา สารคดี และงานกำหนดเอง
- เลือกบรรยากาศเป็นทางลัด แล้วผสมหรือบอกแนวเพิ่มเติมได้
- วางฉากด้วย AI และแก้ภาพ การเคลื่อนไหว เสียงพากย์ และ Prompt รายฉาก
- ทดลองสร้างหนึ่งฉากก่อน หรือสร้างครบทุกฉาก
- ใช้ OpenAI Videos API สร้างคลิปเคลื่อนไหวจริง และใช้ FFmpeg รวมเป็น MP4
- หากสร้างคลิปจริงไม่สำเร็จ ระบบจะแจ้งข้อผิดพลาดและไม่ส่งภาพนิ่งมาแทน
- ดาวน์โหลดชุด Prompt ไปใช้กับเครื่องมืออื่นได้
- รองรับโทรศัพท์ แท็บเล็ต และคอมพิวเตอร์

## ตั้งค่าบน Render

กำหนด `OPENAI_API_KEY` ใน Environment Variables แล้ว Deploy ด้วย Dockerfile คีย์จะอยู่บนเซิร์ฟเวอร์และไม่ถูกส่งไปหน้าเว็บ

ตัวเลือกเพิ่มเติม: `OPENAI_TEXT_MODEL`, `OPENAI_VIDEO_MODEL` (ค่าเริ่มต้น `sora-2`) และ `OPENAI_SPEECH_MODEL`

ใช้ `npm start` เพื่อเปิดในเครื่อง และ `npm test` เพื่อตรวจไฟล์หลัก

## ข้อควรรู้

- การสร้างวิดีโอมีค่าใช้จ่ายตามจำนวนวินาที จึงมีตัวเลือกทดลองหนึ่งฉากก่อน
- ระบบไม่สร้างใบหน้าเลียนแบบบุคคลจริงหรือบุคคลสาธารณะ
- ไฟล์บน Render แบบไม่มี Persistent Disk อาจหายเมื่อบริการเริ่มใหม่ ควรดาวน์โหลดเมื่อสร้างเสร็จ
- OpenAI ประกาศยุติ Videos API รุ่น Sora 2 วันที่ 24 กันยายน 2026 จึงแยกชื่อตัวสร้างไว้เพื่อเตรียมเปลี่ยนผู้ให้บริการภายหลัง
